The Problem

What is a Marine Heatwave?

A period when SST exceeds the 90th percentile of the local climatology (ref. 1985–2014) for ≥5 consecutive days.

In 2023: 146 / 365 days were MHW days (~40%) — unprecedented signal.

Research Question

Can we predict the SST anomaly N days in advance from atmospheric + oceanic precursors?

And — which variables and regions drive the prediction?

Target variable

to_anom = SST − clim_90th

Negative → normal conditions
Positive → MHW conditions


Lead times

Configurable — tested at 7 days


Domain

North Sea / Levante
141 × 201 grid cells (~0.05°)

Anomalisation strategy

to_anom — already an anomaly from ICON-COAST preprocessing (CDO ydrunmean,5, ref 1985–2014). Left unchanged.

u10, v10, msl, ssr — ERA5 absolute values. Day-of-year climatology subtracted in the dataset, using the same 5-day running window and reference period → consistent with to_anom.

Land mask

Applied to ocean variables only. NaN → 0.0 before entering the CNN (zero-value is neutral after normalisation).

LSTM + Temporal Attention

LSTM — temporal memory

LSTM(
  input_size  = 128,   # CNN feature vector per day
  hidden_size = 256,   # internal memory dimension
  num_layers  = 2,     # stacked LSTMs
  dropout     = 0.3,   # between layers only
  batch_first = True
)
# input:  (batch, 60, 128)
# output: (batch, 60, 256)  ← ALL timesteps

The 2nd LSTM layer can learn higher-order temporal patterns — e.g. "a warming trend accelerating over 2 weeks".

Dropout applied between the two layers, not after the last one.

Temporal Attention — Bahdanau style

scores  = Linear(256 → 1)(lstm_out)   # (B, 60)
weights = softmax(scores)              # (B, 60)  — sum to 1
context = sum(lstm_out × weights)      # (B, 256) — weighted mean

The model learns which days in the past matter most for the prediction. This is directly interpretable: high weight at day −20 means "conditions 3 weeks ago are predictive".

Temporal features

Appended before the final FC:

  • year_norm — normalised year (0→1)
  • month_sin — sin(2π·m/12)
  • month_cos — cos(2π·m/12)

Cyclic encoding: Jan and Dec are close in feature space.

Without this, the model cannot distinguish summer vs winter anomalies.

Final FC head

Linear(259 → 64)
ReLU
Dropout(0.3)
Linear(64 → 1)   # SST anomaly

Dataset & Data Splits

Sliding window construction

Each sample: window_size=60 consecutive daily maps → predict target at t + lead_time

Total samples ≈ N_days − window − lead + 1

Target normalised using training stats only — no data leakage.

Block-year split (default)

Full years are assigned randomly to train / val / test. No sample-level overlap within a year.

  • Avoids temporal leakage between splits
  • All seasons represented in all splits (unlike temporal split)
  • Random but reproducible — seeded RNG

Also available: temporal split (past→train, future→test) and random split.

Normalisation

Stats computed on training data only, after split:

  1. Day-of-year climatology (1985–2014, 5-day window) subtracted from ERA5 variables
  2. Per-variable mean and std computed on training time span
  3. Land-masked ocean vars → NaN excluded from stats

Applied identically to val/test at inference time.

Ratios

70 / 15 / 15 (train / val / test) at year level

Explainability (XAI)

Three complementary methods to understand what the model learned

Integrated Gradients

Which variables and spatial regions matter most?

Interpolates from a zero baseline to the actual input in 50 steps, averages gradients × input difference.

Outputs:

  • Bar chart — mean |attribution| per variable
  • Spatial map — where in the domain the model looks

Axiomatic: satisfies completeness and sensitivity.

Attention-weighted Grad-CAM

Which geographic area drives the prediction?

Hooks the last Conv2d layer. For each of the 60 frames: cam_t = ReLU(mean_c(grad × act)). Final map = Σt(attn_t × cam_t).

Outputs:

  • Spatial heatmap overlaid on input
  • Shown for high- and low-anomaly cases

Temporal Attention Weights

Which past days are most predictive?

Native to the architecture — no extra computation. Softmax weights over the 60-day window, extracted via forward_with_attention().

Output:

  • Weight curves per sample (−59 … 0 days)
  • Compared across high/low anomaly events

Attention-weighted Grad-CAM — Detail

Why a custom Grad-CAM?

Standard Grad-CAM is designed for pure CNNs. Here the CNN is embedded inside an LSTM+Attention pipeline:

  • 60 frames are processed by the same CNN
  • The LSTM and attention then decide which frames matter
  • A standard CAM would give one map per frame, ignoring temporal importance

Solution: weight each per-frame CAM by the attention score of that frame.

Algorithm

for t in range(window=60):
    w_t   = grad[t].mean(channels)    # (C,1,1) → scalar per channel
    cam_t = ReLU((w_t × act[t]).sum(channels))  # (H', W')
    cam  += attn_weight[t] × cam_t

cam = cam / cam.max()                  # normalise [0,1]
cam = upsample(cam, size=(lat, lon))   # bilinear → original resolution

Implementation detail

cuDNN is disabled during backward pass — cuDNN LSTM does not support gradients in eval mode.

Forward hooks registered on the last Conv2d — found automatically by iterating cnn_encoder.cnn.

What we analyse

Separately for:

  • High anomaly predictions (top N)
  • Low anomaly predictions (bottom N)

Allows comparison: does the model focus on different regions in MHW vs normal conditions?

Key Design Decisions

Why CNN + LSTM?

MHWs have both spatial structure (which regions warm first?) and temporal dynamics (how do conditions evolve over weeks?).

A pure CNN misses the temporal evolution. A pure LSTM ignores spatial structure. The combined architecture captures both.

Why Attention?

Not all 60 days in the window are equally predictive. A precursor signal 3 weeks ago may matter more than yesterday.

Attention makes this explicit and interpretable — a key requirement for scientific credibility.

Why block-year split?

Temporal split — model never sees future years. But train/val/test may have different seasonality.

Random split — all seasons in all splits, but autocorrelation creates leakage (adjacent days in train and test).

Block-year — best of both: no sample overlap within a year, all seasons represented, full year blocks prevent autocorrelation leakage.

Why three XAI methods?

Each answers a different question and has different assumptions. Convergent evidence across methods is scientifically stronger than any single method.
